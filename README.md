A beginner-to-intermediate mechatronics project built with the Elegoo Uno R3 Starter Kit. This system coordinates a 180-degree servo sweep with real-time ultrasonic echolocation to map physical distance data.

Components Used: Elegoo Uno R3, SG90 Servo Motor, HC-SR04 Ultrasonic Sensor, Breadboard.

Key Concepts: Pulse Width Modulation (PWM), Echolocation math (pulseIn), custom C++ functions, and Serial Monitor data plotting.
